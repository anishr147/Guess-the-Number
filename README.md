# Guess the Number

Guess the Number is a fun and interactive game where players try to guess a randomly generated number within a certain range. The game provides hints and feedback to help players narrow down their guesses. As they get closer to the correct number, the game becomes more challenging and rewarding.

## Features

- Randomly generated number within a specified range
- Hints and feedback to help players guess the number
- Adjustable difficulty level
- Leaderboard to compare scores with friends and family
- Responsive and user-friendly interface

## Installation

1. Clone the repository: `git clone https://github.com/your-username/guess-the-number.git`
2. Navigate to the project directory: `cd guess-the-number`
3. Install the dependencies: `npm install`
4. Start the game: `npm start`

## Usage

1. Enter a number in the input field and press Enter.
2. The game will provide feedback on how close your guess is to the correct number.
3. Use the hints and feedback to narrow down your guesses.
4. Keep trying until you guess the correct number.
5. Track your score and compare it with the leaderboard.
